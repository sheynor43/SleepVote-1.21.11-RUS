# SleepVote

Лёгкий плагин для Paper, который позволяет игрокам голосованием пропустить ночь, ложась спать в кровать.

Собран и протестирован для Paper 1.21.x (целевая версия 1.21.11). English version: [README.md](README.md).

## Возможности

- Когда игрок ложится в кровать ночью, начинается голосование; остальные игроки в этом же мире могут
  нажать "Да"/"Нет" в чате или выполнить `/sleepvote <yes|no>`.
- Если за отведённое время наберётся достаточно голосов "за", ночь пропускается, а статистика "время с
  последнего отдыха" сбрасывается у всех игроков.
- Настраиваемая длительность голосования и необходимый процент голосов.
- Русские и английские сообщения, язык выбирается в конфиге, а сами файлы с текстом можно редактировать.
- Обратный отсчёт и итог голосования можно выводить отдельно либо в чат, либо в action bar.

## Что исправлено в этом обновлении

- **Ложное срабатывание в аду/энде**: раньше взрыв кровати в Нижнем мире или Энде мог запускать
  голосование, потому что плагин проверял только время суток в мире, а не то, удалось ли действительно
  лечь в кровать. Теперь слушатель проверяет `PlayerBedEnterEvent#getBedEnterResult()` и запускает
  голосование только если кровать была успешно использована (`BedEnterResult.OK`) — это ванильное
  поведение возможно только в Верхнем мире и ночью.

## Установка

1. Скачайте `SleepVote-<версия>.jar` со страницы [Releases](../../releases).
2. Положите файл в папку `plugins/` вашего сервера и перезапустите его.
3. Отредактируйте `plugins/SleepVote/config.yml` и `plugins/SleepVote/lang/*.yml` под себя, затем
   перезапустите сервер или перезагрузите плагин, чтобы изменения вступили в силу.

## Настройка (`config.yml`)

```yaml
language: ru            # en или ru

vote:
  duration-seconds: 15      # длительность голосования, сек.
  required-percent: 50      # процент игроков в мире, которые должны проголосовать "за"

display:
  countdown: CHAT           # CHAT или ACTIONBAR - куда выводить обратный отсчёт
  result: CHAT               # CHAT или ACTIONBAR - куда выводить итог голосования

time:
  skip-speed: 20             # на сколько тиков продвигается время мира за один тик сервера
```

Вывод в boss bar намеренно не поддерживается, доступны только `CHAT` и `ACTIONBAR`.

## Файлы языков (`lang/en.yml`, `lang/ru.yml`)

Активный язык выбирается ключом `language` в `config.yml`. Соответствующий файл копируется в
`plugins/SleepVote/lang/` при первом запуске, и его можно свободно редактировать; поддерживаются
цветовые коды `&`.

## Команды

- `/sleepvote yes` — проголосовать за пропуск ночи.
- `/sleepvote no` — проголосовать против.

Также можно нажать на кнопки `[Да]` / `[Нет]`, которые появляются в чате при начале голосования.

## Сборка из исходников

Требуется JDK 21 и Maven.

```bash
mvn package
```

Собранный jar появится в `target/SleepVote-<версия>.jar`.

## Запуск тестов

В проекте есть unit-тесты на базе [MockBukkit](https://github.com/MockBukkit/MockBukkit), которые
проверяют логику голосования и исправление бага с адом/эндом:

```bash
mvn test
```

Обратите внимание: для Surefire задан `forkCount=1` — это нужно для корректной динамической загрузки
плагина внутри MockBukkit.
